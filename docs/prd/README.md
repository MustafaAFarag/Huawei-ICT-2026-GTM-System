# Revenue Workspace PRD

The canonical product specification is [Revenue Workspace — Product Requirements v1](REVENUE_WORKSPACE_PRD_v1.md).

It covers the English-only Twenty-based CRM, GTM, sales, marketing and campaign workspace; a persistent actionable assistant with OpenDesign; phased delivery over a two-month planning horizon; and Azure-first development followed by Huawei migration in month two when credits are available.

This specification supersedes the earlier prototype direction for future development. The existing application and its historical verification results have not been changed by this documentation task. Implementation requires a separate build instruction.
