# Revenue Workspace PRD

The current product specification is [Revenue Workspace — Product Requirements v3](REVENUE_WORKSPACE_PRD_v3.md) ([PDF](REVENUE_WORKSPACE_PRD_v3.pdf)) (13 October 2026). It records the product owner's decisions of 13 October 2026 and is based on the Lara meeting and ten research reports in [`docs/research/`](../research/README.md).

v3 describes one place where non-technical GTM people run outbound: out-of-the-box plays, an AI assistant that runs them, and an OpenDesign Asset Studio, on top of governed connectors and Egypt/Saudi/UAE compliance gates. English is the default; Arabic content is supported. The business model is freemium (Free, Solo, Team, Agency, Enterprise). The December demo runs on Azure as a placeholder; if we pass the December phase, we migrate to Huawei Cloud. The project is open source. Every feature from v1 and v2 stays in the catalogue (v3 §7 and Appendix A).

History: [PRD v2](archive/REVENUE_WORKSPACE_PRD_v2.md) (12 October 2026, proposals) and [PRD v1](archive/REVENUE_WORKSPACE_PRD_v1.md) ([PDF](archive/REVENUE_WORKSPACE_PRD_v1.pdf)). v1 §4 (assistant action contract), §5 (detailed acceptance criteria for later modules), §6 (core records) and §8.2 (migration steps) remain the detailed reference where v3 points to them.

These documents change no application code. Implementation requires a separate build instruction.
